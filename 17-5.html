JAVASCRIPT · TIMERS

两种定时器

setTimeout 只延迟执行一次，用 clearTimeout 取消；setInterval 按固定间隔反复执行，用 clearInterval 停止。下面两个实验台可以亲手启动、取消，并观察日志里的触发时刻。

实验一 · 倒计时炸弹 setTimeout · 只执行一次
--

待命 · 设置秒数后点击「启动」

// 3 秒后执行一次
var xyt_timer = setTimeout(function () {
  console.log("时间到！");
}, 3000);

// 还没触发时可以取消
clearTimeout(xyt_timer);

--:--:--日志会记录启动、触发与取消的时刻

// 每 1000ms 执行一次
var xyt_timer = setInterval(function () {

两者的区别

返回值都是一个数字 ID，用于取消
对比项setTimeoutsetInterval
执行次数延迟到点后只执行 一次每隔一段时间 反复执行
取消方法clearTimeout(id)clearInterval(id)
典型场景延时提示、防抖、一次性动画秒表、轮播图、轮询数据
注意点回调里再次调用自身也能实现循环页面隐藏时浏览器会降频，不能当精确时钟用
