对象的
抽屉与标签

对象是一排贴着标签的抽屉：标签叫属性名（键），抽屉里装的值可以是数字、字符串、布尔值，也可以是另一个对象或数组。左边改抽屉，右边看结果，对象就是这么被「读」和「写」的。

xyt_student // 对象字面量 6 个属性

点击任意属性行，右侧控制台会用「点」和「方括号」两种写法读取它；行尾 × 可以删除该属性。

赋值是「同一把钥匙」

引用类型 · 浅拷贝

把对象赋值给另一个变量，递过去的是同一个抽屉的钥匙，不是复制一份抽屉。下面两张卡都指向同一个对象时，改任意一边，两边显示的值会一起变；用 { ...xyt_a } 浅拷贝后才能各自独立。

xyt_a
score =60
xyt_b
score =60
当前两个变量各自指向独立对象，xyt_a === xyt_b 为 false。

方法里的 this

谁调用，this 就指向谁

对象里放一个函数，它就变成了方法。用 对象.方法() 调用时，this 指向这个对象；一旦把方法单独取出来赋给变量再调用，this 就丢了。

正确姿势：xyt_person.sayHi()

var xyt_person = {
  name: "徐玥桐",
  sayHi: function () {
    return "你好，我是" + this.name;
  }
};
—

错误姿势：var xyt_f = xyt_person.sayHi

var xyt_f = xyt_person.sayHi;
xyt_f();  // this 已经不指对象了

容易踩的四个坑

记住就够了
键名一定是字符串即使写成 {1: "a"}，键也会被转成字符串 "1"；读取时 obj[1] 与 obj["1"] 等价。
点号 vs 方括号键名是变量、或含有中划线、空格时只能用方括号：obj[xyt_k]、obj["user-name"]。
typeof null 是 "object"这是历史遗留问题。判断真对象要用 v !== null && typeof v === "object"。
in 与 hasOwnProperty"name" in obj 会把原型链上的属性也算进来；只想知道自己的属性，用 obj.hasOwnProperty("name")。
