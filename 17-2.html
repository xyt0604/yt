JAVASCRIPT · FETCH REMOTE API

fetch
获取接口数据

用原生 fetch 向远程接口发起一次 GET 请求，把返回的 JSON 数据解析出来，渲染成图片、字段列表与原始报文。该接口返回 Access-Control-Allow-Origin，浏览器可以直接跨域访问，无需代理。整个过程包含加载中、成功、失败三种状态。

接口说明

无需鉴权，直接请求即可

请求示例

// 1. 发起请求
var xyt_res = await fetch("https://dog.ceo/api/breeds/image/random");
// 2. 解析 JSON
var xyt_data = await xyt_res.json();
// 3. 使用数据
xyt_photo.src = xyt_data.message;

fetch 返回的是 Promise，用 await 得到响应对象后，再调用 .json() 把响应体解析成 JavaScript 对象。

返回字段

{
  "message": "https://images.dog.ceo/...",
  "status": "success"
}

message 是随机狗狗图片的地址，status 为 success 表示请求处理成功。注意 status 是业务状态，与 HTTP 状态码不是一回事。

项目说明
请求方法GET，接口不需要携带参数
跨域接口返回 Access-Control-Allow-Origin，浏览器可直接请求
需要鉴权否，公开接口
异常处理网络断开、状态码非 2xx、JSON 解析失败都会进入 catch
