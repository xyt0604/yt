JAVASCRIPT · CONTROL FLOW

JavaScript
程序结构

循环让代码重复执行、条件让代码分支判断 — 两者组合就能实现几乎所有业务逻辑。下方每个示例都包含代码与实时运行输出。

循环结构

for 循环
知道循环次数时首选，三部分：初始化 / 条件 / 更新
// 输出 1~5 for (var xyt_i = 1; xyt_i <= 5; xyt_i++) { console.log(xyt_i); }
运行结果
while 循环
循环次数未知时使用，只要条件为真就一直执行
// 累加直到和 ≥ 10 var xyt_sum = 0, xyt_n = 1; while (xyt_sum < 10) { xyt_sum += xyt_n; xyt_n++; }
运行结果
for…in 遍历对象
遍历对象的所有可枚举属性名
var xyt_person = { name:"徐", age:20, school:"Y2" }; for (var xyt_k in xyt_person) { console.log(xyt_k + "=" + xyt_person[xyt_k]); }
运行结果
break / continue
break 跳出整个循环；continue 跳过本次迭代
// 遇到 7 就跳过，遇到 10 就停止 for (var xyt_j = 1; xyt_j <= 20; xyt_j++) { if (xyt_j === 7) continue; if (xyt_j === 10) break; console.log(xyt_j); }
运行结果

条件结构

if / else 分支
最基础的条件判断，单条件双分支
var xyt_score = 85; if (xyt_score >= 60) { console.log("及格"); } else { console.log("不及格"); }
运行结果
if / else if / else 多分支
按顺序判断多个条件，命中第一个就执行
var xyt_score2 = 85; if (xyt_score2 >= 90) { console.log("等级 A"); } else if (xyt_score2 >= 80) { console.log("等级 B"); } else if (xyt_score2 >= 60) { console.log("等级 C"); } else { console.log("等级 D"); }
运行结果
switch 多路分支
当需要根据同一个变量的不同取值执行不同逻辑时更清晰；break 防止穿透
var xyt_day = new Date().getDay(); switch (xyt_day) { case 0: console.log("周日"); break; case 1: console.log("周一"); break; case 2: console.log("周二"); break; case 3: console.log("周三"); break; case 4: console.log("周四"); break; case 5: console.log("周五"); break; default: console.log("周六"); }
运行结果
三元运算符
if/else 的简写形式，常用于赋值或输出
var xyt_age = 20; var xyt_status = xyt_age >= 18 ? "成年" : "未成年"; console.log(xyt_status);
