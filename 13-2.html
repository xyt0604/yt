SVG 图标的特性

矢量 · 可着色 · 可控描边

currentColor 着色

描边颜色继承自 CSS 的 color 属性，改颜色不需要改 SVG 文件，主题换色非常方便。

描边粗细 stroke-width

直接覆盖 stroke-width，同一图标可以得到不同视觉重量，无需多套素材。

矢量缩放不失真

SVG 是矢量图形，从 18px 放大到 64px 边缘依然清晰，不会出现位图放大后的模糊锯齿。

变换动画

SVG 元素可以直接做 CSS transform 过渡与动画。

sprite 机制

一个 sprite 文件包含全部图标 每个图标用 <symbol> 定义一次 页面用 <use href="#id"> 重复引用

本页面完整 sprite 来自 lucide-static 0.460.0，已下载到 cdn/lucide/sprite.svg；为保证双击 file:// 打开也能显示，页面内联了用到的 18 个 symbol。

两种图标方式对比

SVG 图标 vs 字体图标

SVG 图标（本页 Lucide）

  • 矢量图形，任意缩放都不会失真
  • 可单独控制每条路径、每个细节
  • 可裁剪、可做路径动画、可被读屏识别
  • 通过 <use> 引用 sprite，减少请求数

字体图标（见 13-1.html Font Awesome）

  • 引入 CSS + 字体文件，写 class 即可使用
  • 用 font-size、color 直接控制大小颜色
  • 天然支持旋转、堆叠等字体动画
  • 一个字体文件包含所有图标，按需加载字体族
