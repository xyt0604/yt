字体图标的特性

像用文字一样用图标

字重家族（font-weight）

fa-solid fa-regular fa-brands

同一个名字有三套字形：fa-solid 实心、fa-regular 线框、fa-brands 品牌图标。

尺寸与颜色

尺寸用 fa-xs ~ fa-3x 等 class 控制；颜色、阴影等直接写 CSS，因为图标本质上就是文字。

旋转与动画

fa-spin 匀速旋转、fa-pulse 步进旋转，加载指示器只需要一个 class。

堆叠（fa-stack）

fa-stack 把多个图标叠在一起，配合 fa-inverse 做底衬组合。

按钮中的图标

图标与文字天然对齐，是最常见的用法。

两种图标方式对比

字体图标 vs SVG 图标

字体图标（本页 Font Awesome）

  • 引入 CSS + 字体文件，写 class 即可使用
  • 用 font-size、color 直接控制大小颜色
  • 天然支持旋转、堆叠等字体动画
  • 一个字体文件包含所有图标，按需加载字体族

SVG 图标（见 13-2.html Lucide）

  • 矢量图形，任意缩放都不会失真
  • 可单独控制每条路径、每个细节
  • 可裁剪、可做逐帧动画、可被读屏识别
  • 通过 <use> 引用 sprite，减少请求数
