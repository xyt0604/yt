详情接口

// 根据 ID 获取单个商品
var xyt_res = await fetch(
  "https://dummyjson.com/products/1"
);
var xyt_data = await xyt_res.json();
xyt_data.title; // 商品名

返回一个商品对象，含 images、price、discountPercentage、stock、reviews 等字段。
