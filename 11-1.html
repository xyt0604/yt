Web 前端
长度单位

CSS 中用于定义元素尺寸、间距、字体大小等的度量单位，分为绝对单位与相对单位两大类。

课堂实践 / 11-1

学生：徐玥桐
课程：高级网页设计
形式：HTML / CSS 原生实践

绝对单位

固定物理尺寸，不随环境变化
像素
px

相对于显示器的分辨率，是 Web 开发中最常用的单位。1px 对应屏幕上的一个物理像素点（CSS 像素）。

96px
1in = 96px
点
pt

印刷单位，1pt = 1/72 英寸 ≈ 1.333px。常用于打印样式表。

72pt
1pt = 1/72in
派卡
pc

印刷单位，1pc = 12pt = 16px。来源于印刷排版传统。

6pc
1pc = 12pt
厘米
cm

物理长度单位，1cm ≈ 37.8px。适用于打印媒体查询。

2.54cm
1in = 2.54cm
毫米
mm

物理长度单位，1mm ≈ 3.78px。1cm = 10mm。

25.4mm
1in = 25.4mm
英寸
in

物理长度单位，1in = 96px = 2.54cm。CSS 中定义的物理英寸。

1in
1in = 96px

相对单位

相对于其他元素或视口动态计算
em
em

相对于父元素的 font-size。若父元素 font-size 为 16px，则 2em = 32px。常用于 padding、margin 的等比缩放。

6em（父元素16px）
1em = 父元素 font-size
rem
rem

相对于根元素（html）的 font-size。默认 1rem = 16px。全站统一缩放的推荐单位。

6rem（根元素16px）
1rem = html font-size
视口宽度
vw

相对于视口宽度的 1%。100vw = 视口总宽度。常用于响应式布局和大字号排版。

10vw
1vw = 视口宽度 × 1%
视口高度
vh

相对于视口高度的 1%。100vh = 视口总高度。常用于全屏区块的高度设定。

25vh（示例）
1vh = 视口高度 × 1%
视口最小值
vmin

取 vw 和 vh 中较小的值的 1%。在横竖屏切换时保持比例协调。

5vmin（示例）
min(vw, vh)
视口最大值
vmax

取 vw 和 vh 中较大的值的 1%。确保元素在任一方向上都有足够空间。

3vmax（示例）
max(vw, vh)
百分比
%

相对于父元素对应属性的比例。宽度和高度常用，padding/margin 的百分比基于父元素宽度。

50%
相对于父元素
字符宽度
ch

相对于当前字体中 "0" 字符的宽度。常用于限制文本容器宽度以优化阅读体验。

10ch
1ch = 字符"0"宽度
