把 ECharts 官方示例 npmdepgraph 的数据取到本地，用 graph 系列按节点自带坐标铺开：每个圆点是一个 npm 包，颜色代表所属的依赖簇，连线是「谁依赖谁」。支持滚轮缩放、拖动平移，悬停节点会高亮它的全部相邻依赖。

滚轮缩放、按住拖动平移（roam: true 与 roamTrigger: 'global'）；悬停时用 emphasis.focus: 'adjacency' 聚焦相邻依赖。数据与库文件都放在本地 cdn/echarts 目录下，断网也能打开。

这张图的三个要点

ECharts graph 系列

layout: 'none'

节点坐标直接来自数据里的 x / y，不交给力导向布局计算，所以每次打开位置完全一致，适合固定展示的依赖拓扑。

emphasis.focus

设为 'adjacency' 后，悬停某个包只保留与它直接相连的节点和边，其余自动淡出，一眼看清依赖关系。

数据本地化

示例里的 $.getJSON 依赖 jQuery 和外网地址，在本地打开会跨域失败；这里把 JSON 转成 window.xyt_npmGraph 的 JS 文件，用 <script> 直接引入。
