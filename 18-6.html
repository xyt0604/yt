这两张图分别在说什么

Mermaid 文本即图形

流程图：一条客服链路

用户接入后被分配会话，先做意图识别；置信度高走知识库检索（RAG），命中就直接回复，未命中或置信度低再判断是否转人工；人工处理产生工单，最后统一进日志库做质检与模型迭代。

ER 图：八张核心表

用户、会话、消息、意图、知识库、工单、坐席、评价，靠主外键串起来。一次问答会沉淀为「消息 → 意图 → 知识命中」，转人工则额外生成工单与评价记录。

写法要点

流程图用 flowchart TB + {"判断"} + -- 是 --> 分支标签；ER 图用 erDiagram，关系写成 USER ||--o{ SESSION : "发起"，属性写在花括号里并标注 PK / FK。

离线渲染

Mermaid 库已下载到 cdn/mermaid/mermaid.min.js，用 startOnLoad: false 手动 render()，切换页签时按需渲染，点按钮可导出当前 SVG。
