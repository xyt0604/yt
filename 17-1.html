JAVASCRIPT · JSON DATA FORMAT

JSON
数据格式

JSON（JavaScript Object Notation）是一种轻量的数据交换格式。它借用 JavaScript 的对象写法，但语法更严格：键必须用双引号、不允许注释和末尾逗号，因此任何语言都能安全地解析它。

六条核心规则

写错任何一条都会解析失败
01

键名必须用双引号

JSON 里的键是字符串，"name" 合法，name 或 'name' 都非法。

02

值只有六种类型

字符串、数字、布尔、null、对象、数组，其他如函数、日期都会在序列化时丢失。

03

不允许写注释

// 和 /* */ 都不是合法 JSON，解析时会直接报错。

04

末尾不能有逗号

最后一个成员后面加逗号会报错，这一点和 JavaScript 对象字面量不同。

05

不支持 undefined / NaN

这类值会被 JSON.stringify 直接忽略，放到数组里则变成 null。

06

字符串只能双引号

单引号包裹的字符串在 JSON 中非法，换行等特殊字符必须转义。

两个核心方法

解析与序列化

JSON.parse(str)

var xyt_obj = JSON.parse('{"name":"徐玥桐"}');
console.log(xyt_obj.name); // 徐玥桐

把 JSON 字符串转换成 JavaScript 对象。文本不合法时抛出 SyntaxError，需要 try…catch 捕获。

JSON.stringify(obj, null, 2)

var xyt_str = JSON.stringify({name:"徐玥桐"}, null, 2);
// {
//   "name": "徐玥桐"
// }

把对象序列化为 JSON 字符串。第三个参数是缩进空格数，传 2 即可得到人类可读的格式化结果。
